HOOF RECORDS 2.4.7 — COW PHOTOS + VET REFERENCE

NEW
- Up to 3 photos can be attached to an individual cow before saving.
- Take photo uses the rear-facing phone camera where supported.
- Choose existing allows images from the device photo library.
- Images are resized to a maximum 1800 px long side and JPEG-compressed for practical offline storage.
- Images are stored in IndexedDB; the cow record stores only photo IDs.
- History shows a camera/photo count for cows with stored images.
- Tap the photo count to view that cow's photos.
- Share with Vet sends the actual photo files plus a short cow / lesion / treatment / outcome summary using the device share menu.
- If direct file sharing is unavailable, the photos download and an email draft opens with instructions to attach them.
- Farmer Reports do not embed the photos; they state when photo references are available.
- Undo Last Cow deletes that cow's stored photos.
- Clear All also clears the photo database.

RETAINED
- Previous sessions and Resend Farmer Report.
- Vetlife logo on Farmer Reports.
- Medicine dose (mL) recording.
- Footrot automatically selects Antibiotic.
- Independent hoof tabs.
- Cow number Next/Enter moves to Hoof tabs.
- Portrait-only phone workflow.
- Email / Share Farmer Report.
- No weather / conditions.

UPLOAD
Upload every file in this ZIP directly into the root of the GitHub repository and replace the existing files.

IMPORTANT FOR FUTURE IT HANDOVER
Photos are intentionally device-local and offline using IndexedDB.
When moving the app to another website/domain, backup/restore should include both localStorage records and IndexedDB photos.
